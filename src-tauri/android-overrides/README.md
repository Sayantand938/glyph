# Android overrides

`src-tauri/gen/` is generated by `tauri android init` and is git-ignored, so the
two files Glyph changes there are kept here. After a fresh `tauri android init`,
copy them back:

- `MainActivity.kt` -> `gen/android/app/src/main/java/app/glyph/desktop/MainActivity.kt`
  (pads the web view by the status bar, gesture bar and keyboard, and holds the
  Wi-Fi multicast lock that finding nearby devices needs)
- `AndroidManifest.xml` -> `gen/android/app/src/main/AndroidManifest.xml`
  (adds `ACCESS_WIFI_STATE` and `CHANGE_WIFI_MULTICAST_STATE`)
